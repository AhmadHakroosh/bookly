# Brand assets

Rendered from the mark in `apps/web/src/components/brand/logo.tsx` (the buckle "b") with the
site's Geist wordmark. Regenerate with the script in the repo history of this folder or by
adapting `apps/web/src/app/(platform)/platform/og/route.tsx`.

| File                          | Size     | Use                                                            |
| ----------------------------- | -------- | -------------------------------------------------------------- |
| `bookly-icon-light.png`       | 512×512  | Square icon on white: Stripe Connect icon, app stores, avatars |
| `bookly-icon-dark.png`        | 512×512  | Same on near-black                                             |
| `bookly-logo-light.png`       | 1200×320 | Mark + wordmark on white: Stripe Connect logo, receipts        |
| `bookly-logo-dark.png`        | 1200×320 | Same on near-black                                             |
| `bookly-logo-transparent.png` | 1200×320 | Dark mark and wordmark, no background                          |

Colours: ink `#171717`, paper `#ffffff`, accent (the prong) `#e8965a`.
